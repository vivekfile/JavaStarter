# JavaStarter
A beginner Spring Boot REST API project demonstrating CRUD operations for products using GET, POST, PUT, PATCH, and DELETE endpoints. Built to learn Spring Boot fundamentals, RESTful web services, and Java backend development.


# Spring Boot Product API

This project is a beginner-friendly Spring Boot application created for learning REST API development in Java.

## Features
- Create products (POST)
- Retrieve products (GET)
- Update products (PUT)
- Partially update products (PATCH)
- Delete products (DELETE)

## Technologies Used
- Java
- Spring Boot
- Spring Web
- Maven
- REST APIs

## Purpose
This repository is part of my Spring Boot learning journey and focuses on understanding how to build RESTful APIs, handle HTTP requests, and implement CRUD operations using Spring Boot.
